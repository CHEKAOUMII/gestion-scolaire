🎯 Project Overview
Build a School Management Dashboard web application with the following core features:

Student management and data visualization
Grade tracking and calculation with official coefficients
Firebase/Firestore cloud database integration
Excel file import/export functionality
Multi-year academic data separation
Arabic RTL (Right-to-Left) interface support
🛠️ Technology Stack
Frontend:     HTML5, CSS3, Vanilla JavaScript
Database:     Firebase Firestore (NoSQL cloud database)
Hosting:      Firebase Hosting
Libraries:    
  - Chart.js (charts and graphs)
  - SheetJS/XLSX (Excel file handling)
  - Firebase SDK v9+ (modular)
Font:         Google Fonts - Tajawal (Arabic)

🗄️ Firestore Database Schema
Collection: students
{
  id: string,              // Auto-generated ID
  code: string,            // Massar code (e.g., "G160044350")
  firstName: string,       // الاسم
  familyName: string,      // النسب
  gender: string,          // "ذكر" | "أنثى"
  birthDate: string,       // تاريخ الازدياد
  birthPlace: string,      // مكان الازدياد
  section: string,         // القسم (e.g., "TCSF-1", "1BACSM")
  schoolYear: string,      // الموسم (e.g., "2025/2026")
  createdAt: timestamp,
  updatedAt: timestamp
}
Collection: grades
{
  studentCode: string,     // Reference to student
  subject: string,         // اسم المادة
  schoolYear: string,      // الموسم الدراسي
  semester: number,        // 1 or 2
  cc1: number | null,      // الفرض 1
  cc2: number | null,      // الفرض 2
  cc3: number | null,      // الفرض 3 (optional)
  cc4: number | null,      // الفرض 4 (optional)
  activity: number | null, // نقطة الأنشطة
  average: number,         // المعدل (computed)
  createdAt: timestamp,
  updatedAt: timestamp
}
Collection: settings
{
  currentSchoolYear: string,
  availableYears: array,
  schoolName: string,
  schoolLogo: string
}
⚖️ Grade Calculation Rules (Note 43)
Subject Average Formula
Subject_Avg = (CC_Average × 0.75) + (Activity × 0.25)
Where CC_Average = Sum(CC grades) / Count(CC grades)
General Average Formula
General_Avg = Σ(Subject_Avg × Coefficient) / Σ(Coefficients)

Import Logic
Detect header row automatically (look for "الرمز" or "رمز مسار")
Map columns to fields (flexible column naming)
Parse all sheets if multi-sheet workbook
Add schoolYear to imported data
Merge with existing data (don't overwrite other years)
Show preview before final save

🔐 Firebase Security Rules
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Only authenticated users can read/write
    match /students/{document} {
      allow read, write: if request.auth != null;
    }
    match /grades/{document} {
      allow read, write: if request.auth != null;
    }
    match /settings/{document} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
