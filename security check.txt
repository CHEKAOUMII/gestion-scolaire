  stored dates. For stronger protection, validate the trial status server-side

  Vuln 2: Initial Admin Password Logged to stdout ΓÇö main/db/schema.js:244

  - Severity: Medium
  - Category: information_disclosure
  - Confidence: 8/10
  - Description: When the database is first created, a random admin password is
  generated and written to process stdout via console.log('[SETUP] Initial admin

  plaintext.
  - Exploit Scenario: Electron's main process stdout may be captured by system

  inspect process output via process monitors.
  - Recommendation: Remove the console.log call. Instead, display the initial
