# Data Model: Auto-Generate Trial Sync Key

**Feature**: `017-auto-sync-trial-key`
**Date**: 2026-03-26

## Entities

### sync_config (existing table — no schema changes)

The `sync_config` table is a singleton row (`id = 1`) that stores all sync-related configuration. This feature reads and writes the `license_key` column, which was added by migration `2026-03-034-sync-config-license-key`.

| Column | Type | Nullable | Description |
|--------|------|----------|-------------|
| `id` | INTEGER | PK | Always `1` (singleton) |
| `license_key` | TEXT | Yes | Raw license key string (`GSLK-<base64>.<sig>`). Written by `activateLicense()` for paid keys and by `ensureTrialSyncKey()` for trial keys. Read by `readLicenseKey()` in `credentials.js`. |
| `auth_lambda_url` | TEXT | Yes | Auth Lambda endpoint URL |
| `aws_region` | TEXT | Yes | AWS region, defaults `us-east-1` |
| `school_id` | TEXT | Yes | Massar school code |
| ... | ... | ... | Other sync config columns (pull/push/snapshot settings) |

**No new columns, tables, or migrations are needed for this feature.**

### Trial License Key (generated value — not persisted separately)

The trial key is generated by `createOfflineLicenseKey()` and stored in `sync_config.license_key`. The key's structure is:

```
GSLK-<base64url-encoded-JSON-payload>.<base64url-HMAC-SHA256-signature>
```

Payload contents for a trial key:

| Field | Value | Description |
|-------|-------|-------------|
| `plan` | `'basic'` | Trial plan tier |
| `exp` | ISO 8601 date string | Trial end date (from `getPublicActivationStatus().trialEndDate`) |
| `customer` | `'TRIAL'` | Identifies this as an auto-generated trial key |
| `ov` | `false` | Does not require online validation |
| `dc` | `''` | No device code lock |
| `iat` | ISO 8601 date string | Key generation timestamp |
| `nonce` | 16-char hex string | Random uniqueness token |

### License Status (read-only — from existing functions)

`getPublicActivationStatus()` returns:

| Field | Type | Relevant When |
|-------|------|--------------|
| `status` | `string` | `'trial'` when user is in active trial with no valid paid license |
| `trialActive` | `boolean` | `true` when trial period has not expired |
| `trialEndDate` | `string` (ISO 8601) | Used as `expiresAt` for key generation |

## Relationships

- `sync_config.license_key` ← written by `ensureTrialSyncKey()` (this feature) AND `activateLicense()` (Feature 1)
- `sync_config.license_key` → read by `readLicenseKey()` in `credentials.js` → used by `refreshCredentials()` for Auth Lambda authentication
- `getPublicActivationStatus()` → internally calls `getLicenseStatus()` + `getTrialStatus()` (from `trialService.js`)
- `createOfflineLicenseKey()` → uses `getSigningSecret()` for HMAC signing
