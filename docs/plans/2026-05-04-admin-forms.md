### ✍️ التعهدات (9)

جميعها تحمل حقلاً واحداً إضافياً: `date` — التاريخ (required)

النص الرسمي لكل تعهد مدمج ثابت في قالب الطباعة. هيكل الوثيقة المطبوعة:
1. بيانات التلميذ
2. مربع النص الرسمي للتعهد
3. عبارة "قرأت وفهمت وأتعهد بالالتزام بما جاء أعلاه"
4. التوقيعات: التلميذ(ة) + ولي الأمر + المدير(ة)

نصوص التعهدات:

| المفتاح | النص الرسمي المدمج |
|---|---|
| `pledge_discipline` | أتعهد أنا التلميذ/ة المذكور/ة أعلاه بالالتزام التام بالنظام الداخلي للمؤسسة وباحترام جميع مقتضياته في كل الأوقات. |
| `pledge_no_violence` | نتعهد نحن التلميذ/ة وولي أمره بعدم اللجوء إلى أي شكل من أشكال العنف اللفظي أو الجسدي داخل المؤسسة التعليمية. |
| `pledge_attendance` | أتعهد بالحضور المنتظم إلى المؤسسة وبعدم التغيب إلا لأسباب مشروعة مع تقديم مبررات كتابية في الآجال المحددة. |
| `pledge_no_cheating` | أتعهد بالالتزام التام بمبادئ النزاهة والأمانة خلال جميع الامتحانات والفروض، وعدم اللجوء إلى أي أسلوب غش بأي شكل كان. |
| `pledge_supplies` | أتعهد بإحضار الكتب المدرسية والأدوات اللازمة للدراسة بشكل يومي ومنتظم حسب جدول الحصص. |
| `pledge_no_phone` | أتعهد بالامتناع التام عن استخدام الهاتف المحمول أو أي جهاز إلكتروني مماثل داخل الحرم المدرسي خلال أوقات الدراسة. |
| `pledge_no_smoking` | أتعهد بالامتناع الكامل عن التدخين أو حيازة أي منتجات تبغية داخل المؤسسة التعليمية وفي محيطها المباشر. |
| `pledge_property` | أتعهد بالمحافظة على تجهيزات المؤسسة وممتلكاتها وعدم إتلافها، وأتحمل المسؤولية الكاملة عن أي ضرر أُلحق بها. |
| `pledge_payment` | يتعهد ولي الأمر بسداد جميع الرسوم المدرسية المستحقة في الآجال المحددة من قِبَل الإدارة دون تأخير. |

#### بحث التلاميذ (autocomplete) في النماذج

لجميع الوثائق ذات `studentLinked: true`:

```
┌──────────────────────────────────────┐
│  🔍 بحث عن تلميذ (اسم أو رمز مسار) │
│  محمد أمين...                        │
└──────────────────────────────────────┘
         ↓ نتائج فورية (حد أدنى 2 حرف)
┌──────────────────────────────────────┐
│  محمد أمين بوعزيزي — 3AC1 — E123456 │
│  محمد أمين الزهراوي — 2AC2 — E789012│
└──────────────────────────────────────┘
         ↓ عند الاختيار
  تعبئة تلقائية: studentName + massarCode + className
```

**IPC المستخدم:** `window.api.students.search(query, null, query, schoolYear)`

#### خصائص `FORM_CONFIGS` الجديدة

```js
{
    category: 'health' | 'pledge' | 'notification' | 'disciplinary' | 'form',
    studentLinked: true | false,
    icon: 'fa-...',
    iconClass: 'text-[var(--color-primary)]',
    title: '...',
    description: '...',
    fields: [...]
}
```

#### دالة الفلترة

```js
function filterCards(category, searchText) {
    document.querySelectorAll('.form-card').forEach(card => {
        const matchCat  = category === 'all' || card.dataset.category === category;
        const matchText = !searchText ||
            card.dataset.title.includes(searchText) ||
            card.dataset.description.includes(searchText);
        card.style.display = (matchCat && matchText) ? '' : 'none';
    });
}
```
